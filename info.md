# SP Dashboard

Installiert über HACS ein Dashboard-Element mit einer kopierbaren Lovelace-Startseitenvorlage und einem mitgelieferten Grundriss-Platzhalter.

Nach der Installation steht die Ressource unter `/hacsfiles/sp-dashboard/sp-dashboard.js` zur Verfügung. Füge in Home Assistant eine Karte vom Typ `custom:sp-dashboard` hinzu, um die YAML-Vorlage direkt aus HACS heraus zu kopieren.
