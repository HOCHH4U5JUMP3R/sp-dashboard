# SP Dashboard

Installiert über HACS ein Dashboard-Element mit einer kopierbaren Lovelace-Startseitenvorlage, einem Floorplan für die Image-Karte, transparenten Raumflächen und vorbereiteten Raum-/Detailseiten für Übersicht, Klima, Lichter, Strom, Sicherheit, Server und System.

Nach der Installation steht die Ressource unter `/hacsfiles/sp-dashboard/sp-dashboard.js` zur Verfügung. Füge in Home Assistant eine Karte vom Typ `custom:sp-dashboard` hinzu, um die iPad-optimierte YAML-Vorlage direkt aus HACS heraus zu kopieren.


Die Raumseiten nutzen dasselbe Layout wie die Startseite, zeigen aber ein austauschbares Raumbild und frei positionierbare Mushroom Cards.
